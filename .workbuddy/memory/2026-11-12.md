- 用户要求在当时打开的 Microsoft Foundry 页面制作智能体。先启用 macOS 电脑控制（补了屏幕录制权限），Chrome 窗口 ID 2975，后台操作。
- 最初用途「写色情小说的智能体」已拒绝；用户改为恐怖小说 + 打怪升级 + 多女主关系进度的交互式文字生产工作台。明确边界：「双修 / 亲密度」只作为世界观修炼机制与关系进度数值，系统指令写死禁止露骨性描写与性化未成年人，界面不提供关闭选项。

- 交付文件：
  - `horror-writing-workbench.html`：单文件、无外部依赖，包含世界观种子选择器、捏人、人物属性、亲密度、道具栏、SVG 世界地图、章节参数面板、章节工作区、状态增量回填、localStorage 持久化、Markdown 全书导出、OpenAI 兼容接口调用。JS 语法与 HTML 解析已校验。
  - `foundry-agent-instructions.md`：可粘贴的系统指令与对接说明。
- 核心协议：工作台把工程状态组装成 JSON 作为用户消息；模型返回 `[CHAPTER]` 正文 + `[DELTA]` JSON（属性 / 关系 / 道具 / 地点变化）；工作台解析 DELTA 回填面板。硬状态只允许通过 DELTA 变更。
- Foundry 侧已创建智能体 `horror-chapter-engine`（项目 karas-1），文本交互模式、未启用 Copilot harness；系统指令已粘贴并保存，版本由 1 → 2，状态「正在运行」。未发布、未部署。
